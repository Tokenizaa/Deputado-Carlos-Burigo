# Knowledge Items

Esta pasta materializa unidades atômicas da Knowledge Base metodológica.

Cada item deve seguir o contrato definido em `../FASE-6-KNOWLEDGE-BASE-RAG.md`.

## Tipos

- concepts
- methods
- formulas
- limitations

## Regra

Um item deve representar uma unidade metodológica reutilizável. Não criar um item por pergunta eleitoral.

A mesma unidade pode ser recuperada por múltiplas intents e skills.

## Fonte de verdade

Os itens são derivados do corpus versionado. O índice vetorial é somente uma projeção e pode ser reconstruído.
