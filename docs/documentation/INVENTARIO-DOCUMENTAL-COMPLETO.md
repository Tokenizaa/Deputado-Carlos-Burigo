## Classificação definitiva

Cada arquivo deverá terminar como uma destas classes:

- **CANÔNICO** — fonte operacional atual.
- **REFERÊNCIA** — explica o sistema atual.
- **AUDITORIA** — evidência de uma auditoria/checkpoint.
- **ADR** — decisão arquitetural.
- **MANUTENÇÃO** — registro técnico específico.
- **HISTÓRICO** — preservado, mas não orienta o trabalho atual.
- **ARQUIVO** — preservado para rastreabilidade e sem função operacional.
- **OBSOLETO** — conteúdo superado, mantido apenas quando necessário para histórico.
